# 🔄 LendLoop

### Borrow What You Need. Return When You're Done.

LendLoop is a community-based borrowing and lending application that helps people borrow items they need temporarily instead of purchasing them. It connects lenders who have unused items with borrowers who need them for a limited period, encouraging affordability, resource sharing, and sustainable consumption.

## ✨ Features

- 🔐 **User Authentication** — Simple login and sign-up experience.
- 📦 **Browse Items** — Explore available items across different categories.
- 🔍 **Search and Filter** — Find items based on names, categories, and availability.
- 🤝 **Borrow and Lend** — Connect people who need items with people willing to lend them.
- 📅 **Rental Duration** — Specify borrowing periods and expected return dates.
- 💰 **Refundable Security Deposit** — Lenders can set a security deposit to protect their items.
- 🛡️ **Damage-Based Deductions** — Apply justified deductions for verified damage according to the agreed policy.
- 🔄 **Return Management** — Track borrowed items and their return status.
- 👤 **User Profiles** — Manage personal details and borrowing or lending activity.
- 📱 **Mobile-Friendly Interface** — Designed for a convenient mobile experience.

## 🎯 Problem Statement

People often purchase products they need only for a short period, resulting in unnecessary expenses and underused resources. At the same time, many useful items remain unused in other people's homes.

LendLoop addresses this problem by creating a shared platform where people can borrow and lend items within their community.

## 💡 Proposed Solution

LendLoop provides a convenient way to discover items, request temporary borrowing, agree on borrowing durations, and manage returns. A refundable security deposit helps establish trust between borrowers and lenders, with deductions applied only according to the agreed damage policy.

## ⚙️ How It Works

1. Create an account or log in.
2. Browse available items or list an item to lend.
3. Select an item and request to borrow it.
4. Agree on the borrowing period and security deposit.
5. Use the item during the approved period.
6. Return the item and complete the deposit settlement according to its condition and the agreed policy.
