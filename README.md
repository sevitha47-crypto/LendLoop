# 🔄 LendLoop — Borrow More, Buy Less

**Don't buy it if you only need it temporarily.**

LendLoop is a Flutter-based community borrowing and lending application designed to help people share everyday items for temporary use. It encourages resource sharing, reduces unnecessary purchases, and promotes a more sustainable lifestyle by connecting people who have items to lend with those who need them.

## ✨ Key Features

- 🔐 **User Authentication** — Login and sign-up interface for users.
- 📦 **Item Listings** — Display items available for borrowing and lending.
- 🗂️ **Category-Based Browsing** — Organize items into categories for easier discovery.
- 🤝 **Borrow and Lend** — Support temporary item sharing within a community.
- 💰 **Refundable Security Deposit Concept** — Support a deposit model to encourage responsible borrowing.
- 📱 **Mobile-Friendly Interface** — Built with Flutter for a mobile application experience.
- 🌱 **Sustainable Sharing** — Help reduce waste and unnecessary purchases through reuse.

## 🎯 Project Objective

The main objective of LendLoop is to make temporary access to everyday items easier and more affordable. Instead of purchasing products that are rarely used, people can borrow them from others and lend their own items when they are not needed.

## 📲 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- An Android emulator or a compatible device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sevitha47-crypto/LendLoop.git
   ```

2. Navigate to the project folder:

   ```bash
   cd LendLoop
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## 🔐 Responsible Borrowing

LendLoop is designed around responsible item sharing. A proposed refundable security deposit model can return the full deposit when an item is returned in good condition. Any deduction for damage should follow a clearly defined, fair, and verifiable policy.
